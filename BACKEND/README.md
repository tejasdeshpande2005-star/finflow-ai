# FinFlow AI Backend

A fintech backend project built using Node.js, Express, and PostgreSQL.

## Tech Stack

- Node.js
- Express.js
- PostgreSQL
- bcrypt
- JWT
- dotenv

## Architecture

React Frontend
        ↓
Express Routes
        ↓
Controllers
        ↓
Services
        ↓
PostgreSQL

## Setup

1. Clone the repository
2. Install dependencies

```bash
npm install
```

3. Copy `.env.example` to `.env`

4. Fill in your PostgreSQL credentials.

5. Run the server.

```bash
npm start
```

or

```bash
node server.js
```
